## 为 GMP 教学打造的数字学习空间

GMP 教学的难点从来不只是“内容多”，而是法规语言抽象、知识与生产现场割裂、学生差异难以兼顾，教师也很难持续掌握每个人真正的薄弱点。

GMP Agent 以真实检查缺陷和药品生产场景为入口，将 **AI Agent、课程体系、知识图谱、评测反馈与游戏化仿真**组合成完整产品，让学生从“记住条文”逐步走向“理解风险并作出正确判断”。

## 整体架构

```text
┌─────────────────────────────────────────────────────────────┐
│                         产品体验层                           │
│  学生学习中心 · 教师工作台 · 管理后台 · 虚拟药厂 · 数据看板  │
└──────────────────────────────┬──────────────────────────────┘
                               │ REST API / SSE
┌──────────────────────────────▼──────────────────────────────┐
│                      AI 交互与业务服务层                     │
│  AI 助教 · 个性化计划 · 课程与题库 · 学习反馈 · 角色权限      │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│                         Agent 能力层                         │
│  LangGraph 编排 · 混合检索 RAG · 分层记忆 · 工具调用 · 自检  │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│                         数据与评测层                         │
│  MySQL · 法规库 · 知识图谱 · 学习轨迹 · 黄金集 · 性能基线     │
└─────────────────────────────────────────────────────────────┘
```

整体采用中心化 Agent 编排：Tutor Agent 维护对话和任务状态，RAG、记忆和工具作为受控能力接入。这样既保留 Agent 对开放问题的适应性，也能满足教学产品对稳定性、可解释性和权限边界的要求。

| 工程关注点 | 当前实现 |
|---|---|
| **可信回答** | HNSW + MySQL FULLTEXT 混合检索、`gte-rerank` 精排、法规来源标注 |
| **上下文管理** | 用户画像、递归摘要、工作记忆、经验召回，避免无限拼接历史 |
| **行为安全** | 参数校验、超时重试、循环守卫、重复调用检测、HITL 人工确认 |
| **性能意识** | 数据库连接池、共享检索执行器、请求级阶段耗时、受控并发基线 |
| **可验证迭代** | 302 项测试、固定黄金集、客观题与专家论述题专项评测 |

### 环境要求

- Node.js 20+
- Python 3.11+
- MySQL 8+

```bash
git clone https://github.com/Cryptic-LEY/gmp-agent.git
cd gmp-agent

# 初始化数据库
mysql -u root gmp < gmp-web/db/migrations-mysql/0000_init_mysql.sql

# 启动 Web
cd gmp-web
npm install
cp .env.local.example .env.local
npm run dev

# 启动 Agent API
cd ../gmp-api
pip install -r requirements.txt
cp .env.example .env
uvicorn main:app --reload --port 8001
```

Web 默认运行在 `http://localhost:3000`，Agent API 默认运行在 `http://localhost:8001`。完整配置见 [SETUP.md](./SETUP.md)。
